# Time Tracker

Simple stopwatch time tracker with labeled sessions.

## Features
- Start / stop active timer
- Label sessions
- Total duration summary
- localStorage history

## Limitations
- Not a payroll-grade timesheet
- Timer pauses if the tab sleeps (browser throttling)

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- localStorage persistence

## Run
```bash
npm install
npm run dev
```

## Honesty notes
- Portfolio mini-app showcase
- Not multi-tenant SaaS
